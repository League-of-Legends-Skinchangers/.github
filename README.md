## ❓ FAQ

### Do I need to run it as Administrator?
No. This repository is an informational reference and does not include an executable or overlay.

### Does this repository include a skinchanger executable?
No. It covers cosmetic categories, custom skin formats, and community skin management concepts.

### Does it work on Windows 11?
Yes. The reference can be viewed on Windows 11 using a standard web browser.

### Can a skinchanger unlock paid League of Legends skins?
Tools that provide Riot's paid skins without ownership fall under Riot's stated skin-hack restrictions. This reference does not provide paid-skin unlocking functionality.

### Are custom skins officially supported by Riot?
Riot does not guarantee compatibility with custom artwork and reserves the right to act against applications that provide its assets for free. Review Riot's current third-party application policy before using cosmetic modifications.
